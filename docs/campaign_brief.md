# Campaign brief

## Campaign title

Using Machine Learning for Community Engagement: Kosher Edition

## One-line description

A practical community data project that uses machine learning to help people find, understand, and share reliable kosher food options across the South Shore of Massachusetts.

## Core idea

Kosher food discovery is not just a restaurant search problem. It is a community coordination problem. Families, visitors, synagogues, students, and small businesses all need accurate information, but that information is often scattered across certifier pages, menus, store listings, community posts, and word of mouth.

This project uses structured data and menu-focused machine learning to make that information easier to find, explain, and share.

## Public framing

This is a small, local example of responsible AI:

- Start with source-linked community data.
- Respect certification scope and uncertainty.
- Use machine learning to classify menus and organize information.
- Help communities communicate better.
- Support local kosher and kosher-relevant businesses.

## LinkedIn-ready post

Using machine learning for community engagement — Kosher edition.

Most AI demos chase scale. This project starts with something local and practical: helping people find reliable kosher food options across the South Shore of Massachusetts.

Kosher food discovery is a real coordination problem. Information is scattered across certifier pages, menus, store listings, community groups, and word of mouth. A family planning breakfast near Sharon, a visitor heading toward Plymouth, or a synagogue sharing a resource all need the same thing: clear, current, source-linked information.

The goal is to turn fragmented public information into structured community data. From there, menu-focused machine learning can help classify food categories, identify dietary tags, normalize prices, and generate helpful social posts or community updates.

The important part is trust. The system should never guess kosher status. Every recommendation needs a clear label: verified active, verified limited scope, watchlist, historical, or unverified lead.

That is the version of AI I want to build more of: practical, local, transparent, and useful to real communities.
